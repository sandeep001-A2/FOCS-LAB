# Foundation of Cyber Security (FOCS) Lab

This repository contains the lab experiments, procedures, codes, and execution screenshots for the Foundation of Cyber Security (FOCS) Lab course.

---

## Index of Experiments

| Experiment | Title | Description | Included Files |
| :--- | :--- | :--- | :--- |
| **Experiment 1** | **Information Gathering using Google Dorking** | Passive reconnaissance using Google search operators (`site:`, `filetype:`, `intitle:`, `inurl:`, etc.) | • `Experiment 1`<br>• `Experiment 1 screenshorts.pdf` |
| **Experiment 2** | **Buffer Overflow Vulnerabilities & Mitigations** | Demonstrating buffer overflows in C (`strcpy()`, structures, memory layout) and safe coding practices (`fgets()`, `snprintf()`, `scanf("%Ns")`) | • `Experiment 2`<br>• `Experiment 2 codes screenshorts.pdf` |
| **Experiment 3** | **Host Scanning & Service Discovery using Nmap** | Host discovery (`-sn`), TCP SYN scans (`-sS`), service/version detection (`-sV`), UDP scans (`-sU`), and custom listener testing with Ncat | • `Experiment 3`<br>• `Experiment 3 SS.pdf` |
| **Experiment 4** | **Packet Capturing & Analyzing using Wireshark** | Installing Wireshark, capturing network traffic, and analyzing TCP, UDP, DNS, and ICMP packets across protocol layers | • `Experiment 4`<br>• `Experiment 4 Installation of Wireshark`<br>• `Experiment 4 Screenshots & Execution .pdf` |
| **Experiment 5** | **Brute Force & Dictionary Attacks using Hydra** | Testing authentication mechanisms against weak passwords using Hydra dictionary (`-P`) and brute-force (`-x`) attacks | • `Experiment 5`<br>• `Experiment 5 Kali Linux  and Hydra Installation`<br>• `Experiment 5 Screenshots & Execution .pdf` |
